# TexA

**TexA (Textile Assistant)** is an AI assistant built to make textile knowledge more accessible. It helps students, educators, researchers, and industry professionals find accurate, concise, and practical answers to textile-related questions.

## Features

* AI-powered textile assistance
* Instant answers to textile concepts
* Covers fibers, yarns, fabrics, dyeing, finishing, garments, and manufacturing
* Designed for learning, research, and everyday reference
* Clean, responsive interface

## Getting Started

Clone the repository:

```bash
git clone https://github.com/blackarchparrot/TexA.git
```

Run locally by opening `index.html` or deploy it to your preferred hosting platform.
